# Chapter Materials — Advanced Graphs, Strings, and Limits

## Sequence

- `2400-advanced-graphs-strings-limits.ipynb`: landing page, essential concepts, learning objectives, chapter flow, glossary, slides placeholder
- `2401-graph-traversal.ipynb`: BFS, DFS, BFS path reconstruction, connected components
- `2402-shortest-paths-strings.ipynb`: path algorithm assumptions, direct string matching, prefix tables, KMP-style matching, strategy choice
- `2403-limits-project.ipynb`: growth limits, exact/pruned/approximate strategies, final algorithm comparison project, BFS/DFS comparison example
- `assignments/preview.ipynb`: glossary and concept preview
- `assignments/lab.ipynb`: required technical lab for traversal, string matching, and growth warnings
- `assignments/homework.ipynb`: true/false and coding practice

## Coverage Notes

- This chapter synthesizes earlier algorithm ideas rather than surveying every advanced algorithm.
- BFS/DFS should connect back to graph representations, queues, stacks, and backtracking.
- String matching should introduce prefix-aware reasoning without turning into a long text-algorithms chapter.
- Computational limits should focus on recognizing growth and choosing exact, approximate, pruned, or heuristic approaches.

## Maintenance Notes

- C# examples should remain standalone because students may run any cell directly in Live Code.
- Keep graph and string examples small enough to trace by hand.
- When adding advanced topics, require a clear reason and a small runnable example.
