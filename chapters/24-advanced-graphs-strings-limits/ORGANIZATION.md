# Chapter Organization — Advanced Graphs, Strings, and Limits

## Learning Objectives

Students should be able to implement graph traversal, explain shortest-path
assumptions, compare string-search strategies, and recognize when a problem's
computational growth makes exact solutions impractical.

## Sequence

- `2400-advanced-graphs-strings-limits.ipynb`: chapter landing page with essential concepts, learning objectives, chapter flow, glossary, and slides placeholder
- `2401-graph-traversal.ipynb`: breadth-first search, depth-first search, unweighted path reconstruction, and connected components
- `2402-shortest-paths-strings.ipynb`: shortest-path assumptions, direct string matching, prefix tables, KMP-style matching, and strategy selection
- `2403-limits-project.ipynb`: growth limits, exact/pruned/approximate choices, final comparison deliverable, and a BFS/DFS comparison example
- `assignments/index.ipynb`: assignment TOC parent
- `assignments/preview.ipynb`: pre-class concept quiz
- `assignments/lab.ipynb`: required technical lab for BFS, DFS, paths, string matching, and growth estimation
- `assignments/homework.ipynb`: post-class true/false and coding practice

## Coverage Boundary

Chapter 24 is the capstone algorithms chapter. It should help students choose
among strategies and explain limits. It should not attempt a complete advanced
algorithms course. Keep traversal, string matching, and computational limits
concrete and connected to the earlier chapters.

## Assignment Plan

- Preview: BFS, DFS, string matching, prefix tables, and approximation.
- Lab: implement traversal, reconstruct an unweighted path, direct string matching, and growth estimates.
- Homework: reinforce visited sets, connected components, character-comparison counts, prefix tables, and algorithm recommendations.
