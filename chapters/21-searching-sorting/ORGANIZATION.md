# Chapter Organization — Searching and Sorting

## Learning Objectives

Students should be able to select a search algorithm based on data conditions,
trace elementary sorting algorithms, explain their growth rates, and compare
implementations using correctness tests and operation counts.

## Sequence

- `2100-searching-sorting.ipynb`: chapter landing page with essential concepts, learning objectives, chapter flow, glossary, and slides placeholder
- `2101-searching.ipynb`: linear search, search contracts, comparison counts, binary search, binary-search tracing, and search-choice guidance
- `2102-sorting.ipynb`: swap operation, selection sort, insertion sort, bubble sort, comparison counting, and library sorting guidance
- `2103-comparison-lab.ipynb`: correctness tests, search counts, elementary-sort counts, merge-sort growth comparison, and recommendation writing
- `assignments/index.ipynb`: assignment TOC parent
- `assignments/preview.ipynb`: pre-class concept quiz
- `assignments/lab.ipynb`: required technical lab for linear search, binary search, selection sort, insertion-sort counts, and algorithm-choice recommendations
- `assignments/homework.ipynb`: post-class true/false and coding practice

## Coverage Boundary

Chapter 21 is the practical searching and sorting chapter. It should reinforce
Chapter 19's complexity language and Chapter 20's merge sort, but it should not
become an advanced sorting survey. Keep Shell sort, quicksort, and production
benchmarking as later extensions.

## Assignment Plan

- Preview: search preconditions, swaps, elementary sorts, and Big-O recognition.
- Lab: implement basic searches and sorts, count comparisons, and make a recommendation from data conditions.
- Homework: reinforce string search, missing-target counts, binary-search tracing, bubble sort, and library sort plus binary search.
