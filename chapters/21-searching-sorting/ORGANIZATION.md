# Chapter Organization — Searching and Sorting

## Learning Objectives

Students should be able to select a search algorithm based on data conditions,
trace elementary sorting algorithms, explain their growth rates, and compare
implementations using correctness tests and operation counts.

## Sequence

- Linear search and search contracts
- Binary search and sorted data
- Exchanges and elementary sorting
- Insertion, selection, and bubble sort
- Comparison lab with merge sort
