# Chapter Materials — Trees and Binary Search Trees

## Sequence

- `1600-trees-bst.ipynb` — landing page with overview, objectives, Chapter Flow, video, and glossary
- `1601-tree-structure.ipynb` — tree vocabulary, recursive structure, traversal orders, height, and leaf counting
- `1602-binary-search-trees.ipynb` — BST invariant, search, insertion, inorder testing, shape/performance, and removal preview
- `1603-tree-lab.ipynb` — implementation lab for traversals, search, insertion order, and height comparison
- `assignments/preview.ipynb` — Preview
- `assignments/lab.ipynb` — Lab
- `assignments/homework.ipynb` — Homework

## Coverage Notes

- Core coverage includes tree vocabulary, binary node references, preorder/inorder/postorder traversal, BST invariant, search, insertion, minimum/maximum, and height.
- Removal is introduced conceptually through the three major cases, but the coding work focuses on traversal, search, insertion, and shape.
- Balancing is framed as motivation for later self-balancing trees rather than implemented in this chapter.
