# Chapter Organization — Data Collections

## Learning Objectives

Students should be able to choose between arrays, lists, and dictionaries for
common storage tasks; write basic `List<T>` code for growing ordered data; and
write basic `Dictionary<TKey,TValue>` code for key/value lookup.

## Sequence

- Data collections (conceptual foundations: access patterns, generics, namespaces)
- Lists (`List<T>`)
- Dictionaries (`Dictionary<TKey,TValue>`)
