## Sequence

- CS ideas and problem solving
- Development tools and environment
- Program structure in C#
  - The five C# structures: REPL quick checks, file-based apps, console projects
    with top-level statements, console projects with explicit `Main`, and
    project/solution workspaces
  - Choosing the right structure for quick experiments, labs, homework, and
    larger projects
  - Syntax shared by all structures: comments, braces, semicolons, and blocks

## Notes

- `0103-program_structure.ipynb` introduces .NET 10 file-based apps with
  `dotnet run app.cs` as a quick single-file workflow, while keeping normal
  .NET projects as the durable workflow for labs, homework, and course projects.
- `0103-program_structure.ipynb` should lead with the five-structure decision
  table before details. Students need the map first: quick checks in
  `csharprepl`, saved one-file experiments with `dotnet run app.cs`, normal
  apps with `dotnet new console`, explicit structure with `--use-program-main`,
  and multi-file work with projects/solutions.
