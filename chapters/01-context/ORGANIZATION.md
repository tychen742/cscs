# Chapter Organization: Getting Started with C#

## Instructional role

Introduce computing as problem modeling and checking, then connect it to a small saved C# application. Assume no programming experience. Keep decisions, loops, methods, and class design as previews of later chapters rather than prerequisites.

## Teaching sequence (110 minutes)

| Section | Minutes | Focus |
| --- | ---: | --- |
| Computing Concepts | 40 | Requirements and IPO, algorithms and test cases, sequential output, data representations, execution pipeline, error categories |
| Development Tools | 35 | SDK verification, terminal directory context, edit/build/run, local Git states |
| C# Program Structure | 35 | Workflow map, file versus project, top-level versus Main, namespace and wrapper reading, syntax and tracing |

Pause for predictions and nearby exercises. Test the ordinary, empty, and all-completed workload cases. Distinguish a successful build from a correct business answer.

## Assignments

- Preview: ten multiple-choice conceptual checks.
- Lab: five connected service-desk report stages, then local project build/run and boundary-case evidence.
- Homework: five applied true/false questions and five inventory/reporting coding questions.
- Historical Mercurial lab remains inactive and is excluded from the TOC.

## Deferred work

Author slides after content completion. Slide content belongs to the book; Press provides delivery and access controls. Detailed shell and team Git workflows belong in appendices or later practice.
