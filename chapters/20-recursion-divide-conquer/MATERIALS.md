# Chapter Materials — Recursion and Divide-and-Conquer

## Purpose

Chapter 20 connects recursive program structure to algorithm design. Students
should leave able to trace recursion, state base cases and progress measures,
and recognize divide-and-conquer patterns.

## Planned Examples

- factorial, Fibonacci, and recursive search
- call-stack tracing
- binary search as a halving strategy
- merge sort and merge operations
- recurrence-based performance analysis
