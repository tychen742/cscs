# Chapter Organization — Society, Ethics, and the Profession

## Learning Objectives

1. Explain, with real cases, how software defects and design choices can harm people and organizations
2. Apply a four-question checklist to analyze an ethical decision in a software project
3. Write C# methods that mask personal data, validate untrusted input, and log events without leaking secrets
4. Recognize injection as a security risk created by building commands from user input
5. Describe professional responsibilities for licenses, attribution, AI-assisted code, and accessibility

## Sequence

- Computing and society: case studies, defects at scale, ethical analysis, professional codes
- Privacy and security in code: personal data, masking, untrusted input, injection, logging
- Professional practice: licenses, AI assistants, accessibility, internationalization, communication

## Notes

The chapter sits after Exceptions and Testing so that it can build on boundary
tests and `TryParse`, and before Part II so that privacy and security habits are
in place before students handle files, collections, and databases. CS2023 asks
for SEP topics across courses, so later chapters should call back to this one
(see the Gaps list in `authoring/CS2023_ALIGNMENT.md`).
