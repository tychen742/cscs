# Completed array lab algorithms

**Teaching role:** Completed legacy exercise; not a current lab solution. See the [instructor walkthrough](../../../assignments/instructor_support/demos/08_array_lab.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project array_lab.csproj
```

The verification run checks for these results:

- `Even count: 3`.
- `Pairwise sums: 9 3 14`.
- `Ascending: True`.

This is the completed demonstration version, with implementations rather than assignment stubs.
