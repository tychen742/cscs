# Command-line arrays, rectangular arrays, and jagged arrays

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project arrays_demo.csproj
```

For the verification example, supply these command-line arguments:

```bash
dotnet run --project arrays_demo.csproj -- 1 2 3
```

The verification run checks for these results:

- `There are 3 command line parameters.`.
- `ints.Length: 12`.
