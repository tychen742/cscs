# Calling an instance method

**Teaching role:** Supplementary instance-method example. See the [instructor walkthrough](../../../assignments/instructor_support/demos/_extras_contact_demo.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project contact_demo.csproj
```

The verification run checks for these results:

- `Name is TY`.
- `Phone is 333`.
