# While loops and a number guessing game

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project while_loop_demo.csproj
```

Guess integers from one through 100. The program prints `Higher`, `Lower`,
or `Correct!` and ends when the guess is correct.

The verification run checks for these results:

- `Correct!`.
