# Basic arithmetic library

**Inventory role:** Helper library. Arithmetic library used by the paired test suite.

**Teaching role:** Testing demonstration library. See the [instructor walkthrough](../../../../instructor_support/demos/06_math_tests_math_app.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Build the reusable library:

```bash
dotnet build math_app.csproj
```
