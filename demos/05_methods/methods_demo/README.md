# Method calls, parameters, and return values

**Teaching role:** Concept companion. See the [instructor walkthrough](../../../instructor_support/demos/05_methods_demo.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project methods_demo.csproj
```

Example console input, one response per line:

```text
2
3
```

The verification run checks for these results:

- `2 + 3 = 5`.
- `Old MacDonald had a farm`.

This companion’s `LastFirst` greeting is its own demonstration contract; it is
not the lab’s lastname-first `LastFirst` answer. The lesson and lab specify that
separate contract explicitly. For the exact Product Code Report reference, use
`demos/05_methods/sku_report_lab_solution.cs` and the linked instructor lab walkthrough.
