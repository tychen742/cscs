# File-driven response lab starter

**Inventory role:** Student starter. File-response exercise starter; default hard-coded mode only.

Run `dotnet run` in this folder to study the hard-coded version. Change StartupObject to `IntroCS.FakeHelp` in the project, then complete the three FileUtil methods. Data files are local synthetic examples. The completed integrated demo is in `demos/08_collections/help_responses`; this folder is the exercise starter.
