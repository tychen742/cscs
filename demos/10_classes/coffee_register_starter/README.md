# Coffee Register Starter

This .NET 10 console project matches Chapter 10 Lab stage five. Complete ToString in Program.cs. Download both source files into one folder and open it in VS Code.

```console
dotnet run --project coffee_register_starter.csproj
```

Expected final shift totals: Front $32.04, Drive-thru $15.28, store $47.32. The unfinished starter compiles and prints empty register summary lines until ToString is completed. Each process starts receipt numbers at 1001. See the notebook for earlier stages and the full reference output.
