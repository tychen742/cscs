# Enum values and their integer representation

**Inventory role:** Demo. Named enum values and their underlying integer values.

**Teaching role:** Supplementary type example. See the [instructor walkthrough](../../../instructor_support/demos/10_enum_demo.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project enum_demo.csproj
```

The verification run checks for these results:

- `Medium`, `3`.
