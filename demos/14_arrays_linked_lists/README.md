# Linear-list verification

Create a temporary console project using the installed .NET SDK, copy `WorkOrderLists.cs` to its `Program.cs`, and run `dotnet run`. This material contains the chapter's complete generic implementations and contract checks. Expected final output: `All linear-list checks passed.`

## Automated Verification

From the repository root, run `python3 scripts/verify_demos.py`. The verifier copies this source unchanged into a temporary .NET 10 project and checks its output. The manual commands above remain available for exploration.
