# Bank-account encapsulation demonstration

**Teaching role:** Supplementary example; not a current lab solution. See the [instructor walkthrough](../../../instructor_support/demos/13_oop_lab.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project oop_lab.csproj
```

The verification run checks for these results:

- `Final balance: 125`.

This project links the bank-account source in `../oop_demo/`; keep both folders together.
