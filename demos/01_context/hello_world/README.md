# First console application

**Inventory role:** Demo. First C# console program and printed greeting.

**Teaching role:** Exact first-program example. See the [instructor walkthrough](../../../instructor_support/demos/01_hello_world.md).

Requires the .NET 10 SDK. Open this folder in VS Code.

Run the console application:

```bash
dotnet run --project HelloWorld.csproj
```

The verification run checks for these results:

- `Hello, World!`.
