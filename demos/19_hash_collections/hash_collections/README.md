# HashChecks

**Inventory role:** Demo. Chained map and set reference checks

Part IV reference project. Requires .NET 10, with no package dependencies.

```sh
dotnet run --project demos/19_hash_collections/hash_collections
```

The program checks ordinary and boundary behavior against an independent expected result or library reference and throws on failure. The model is in `Model.cs`; `Program.cs` contains the verification driver. Browser lesson examples include their own complete setup.
