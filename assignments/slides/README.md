# Instructor lecture decks

These editable PowerPoint files contain teaching notes, quick-check answers,
and suggested exercise responses. They are kept outside the student book build.
The corresponding student HTML decks omit notes and are linked once from each
chapter landing page.

Each deck follows the existing chapter order. The opening slide's notes list
the starting slide for every part. Core parts follow the reading sequence;
supporting and optional parts are labeled explicitly and add no required class
meetings. Reading pages and meetings are not interchangeable: use the chapter's
`ORGANIZATION.md` to distribute time within its existing weekly allowance.

Before class, read the notes, open the linked lesson, and run the worked examples.
Notes explain the expected output, likely mistakes, discussion questions, and
the answer to each quick check. Students can predict output before a live demo;
the slide's saved output is available if the local toolchain is unavailable.

Use PowerPoint Presenter View to keep notes off the projected display. To show
code beside the slides on a Mac, open the slideshow in a window with Cmd+5 and
tile it with VS Code or the lesson notebook. The HTML deck can also be tiled with
the book. Browser examples run independently; for local projects follow the
chapter's stated entry-point convention.

Assign Preview before class, use Lab for connected guided practice, and assign
Homework after instruction. Slide quick checks are ungraded classroom practice;
they do not introduce assessment IDs or replace the existing submission panel.
Use the existing appendix track for durable project submissions.

Sources, rebuild commands, code verification, and output checks are documented
in `scripts/slides/README.md`. Review changes and regenerate both outputs whenever
the corresponding lessons or assignments change.
